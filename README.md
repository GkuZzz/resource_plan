# Resource Planner — годовая диаграмма Ганта

React-прототип для планирования занятости сотрудников по проектам. Пересечения назначений разрешены и отображаются отдельными полосами.

## Запуск

Требуется Node.js 18+.

```bash
npm install
npm run dev
```

Откройте адрес, который выведет Vite (обычно http://localhost:5173).

## Возможности

- Просмотр назначений на годовой шкале с точностью до дня.
- Добавление назначений через кнопку в шапке или «+» у сотрудника.
- Редактирование по нажатию на полосу.
- Удаление назначений.
- Одновременные назначения на разные проекты без запрета пересечений.
- Фильтры по сотруднику и проекту.
- Локальное сохранение в localStorage и экспорт JSON.

## Где изменять сотрудников и проекты

В начале `src/App.jsx` отредактируйте массивы `PEOPLE` и `PROJECTS`.

## Ограничения MVP

Это самостоятельное веб-приложение, не встроенный официальный модуль Яндекс Трекера. Пока нет API-интеграции, общего сервера, авторизации, drag-and-drop и синхронизации между пользователями. Для совместной работы потребуется backend и база данных. Назначения сохраняются только в текущем браузере.
