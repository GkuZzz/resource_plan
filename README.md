# Resource Planner — годовая диаграмма Ганта

React-прототип для планирования занятости сотрудников по проектам. Поддерживает параллельную работу и переключение ресурса на приоритетный проект с автоматическим продолжением прерванных задач.

## Запуск

Требуется Node.js 18+.

```bash
npm install
npm run dev
```

Откройте адрес, который выведет Vite (обычно http://localhost:5173).

## Возможности

- Просмотр назначений на годовой шкале в разрезе месяцев или ISO-недель.
- Добавление назначений через кнопку в шапке или «+» у сотрудника.
- Редактирование по нажатию на полосу.
- Перетаскивание полосы мышкой для сдвига всего интервала.
- Изменение начала и окончания назначений перетаскиванием краёв полосы.
- Удаление назначений.
- Одиночные фильтры по сотруднику и проекту.
- Выбор режима при пересечении нового назначения с другим проектом:
  - **Вести параллельно** — оба проекта остаются активными одновременно.
  - **Приоритетный проект** — текущий проект приостанавливается, а оставшаяся работа продолжается со следующего дня после завершения приоритетного проекта.
- Обязательное подтверждение режима распределения ресурса при обнаружении пересечений.
- Визуальная маркировка приоритетных назначений звездой и штриховкой.
- Локальное сохранение в localStorage и экспорт JSON.

## Проверка

```bash
npm test
npm run build
```

Тесты проверяют разрыв интервала, перенос полностью перекрытого назначения, продолжение незавершённой работы и независимость назначений других сотрудников.

## Публикация

При отправке изменений в ветку `main` workflow `.github/workflows/deploy-pages.yml` запускает тесты, собирает приложение и публикует содержимое `dist` в GitHub Pages:

https://gkuzzz.github.io/resource_plan/

## Где изменять сотрудников и проекты

В начале `src/App.jsx` отредактируйте массивы `PEOPLE` и `PROJECTS`.

## Ограничения MVP

Это самостоятельное веб-приложение, не встроенный официальный модуль Яндекс Трекера. Пока нет API-интеграции, общего сервера, авторизации и синхронизации между пользователями. Для совместной работы потребуется backend и база данных. Назначения сохраняются только в текущем браузере.
